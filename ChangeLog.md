# AreaTree 7.5.5

- Added `anchor-area`, `document-info.display-doctitle`, `expansion-text`, `text-treat-as`, `text-overflow`, `keep-together-within-inline-dimension`, `font-feature-settings`, `layer`, `border-connection-form`, `text-stroke-color`, `text-stroke-width`, `printer-marks-over-content`, and `outline-external-destination`.
- `annotation-type` values `Highlight`, `StrikeOut`, `Underline`, and `Squiggly`
- `leader.rule.style` values `wavy`, `double-wave`, and `double-wavy`.
- `alttext`, `box-decoration-break`, `display`, `display-role`, `font-face`, `image-orientation`, `next-continued`, `prev-continued`, and `title` available on more elements.
- `background-color` and `background-setup` optional on `TableRowGroupArea`.
- `pdftag` can be empty with 'new-tagging-mode' (https://www.antenna.co.jp/AHF/help/en/ahf-optset.html#new-tagging-mode).
- Enumerated values for `row-group-type`.
- `row-number` is decimal.
- `z-index` can be `auto`.
- Corrected some allowed values.
